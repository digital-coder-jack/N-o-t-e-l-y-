# Notely

An AI-powered student notebook web app built with Vite, React, and TypeScript.

## Screens included

- Overview dashboard
- Notebook library and notebook editor
- Course materials with PDF reader
- Flashcard library and review flow
- Quiz library, quiz-taking, and results
- Calendar
- Recorded lectures library and player
- Workspace search
- Floating Notely Assistant
- Tasks
- Account and settings

## Development

```bash
npm install
npm run dev
```
